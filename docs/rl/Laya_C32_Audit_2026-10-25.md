# C32 audit and actionable findings

Recorded 2026-10-25 01:35 IST. Evidence directory:
`data/laya-orchestration/c32-20261025/`; helper reports are evidence, not authority.

## Changes implemented

**Plastic startup:** C5-v2 starts at the first new output after explicit episode
initialization. Within the first 120 game seconds, any two consecutive positive
30-second rates qualify when the smaller is at least 80% of the larger. Later
stock or gas-supply pauses do not revoke proof. Delivery stays C4; ongoing
service remains separate. Production is aggregate plastic items for the named
force/surface, not producer lineage. A maximum of five samples is retained.

`production-startup-v2` is armed before selected operations. Reading/resuming
cannot create a late replacement window. The canonical save already has 392
historical plastic items produced; rejecting a nonzero initial counter would
wrongly make this experiment unobservable. Explicit episode-start arming
baselines that history. The same run retains its watch across save/load.
Missing evidence remains unknown. Counter errors after a valid stable pair
preserve proof and are recorded; errors before proof remain unknown. RCON
protocol failures in the sampler do not abort the other checkpoint observations.
The catalog now labels C5-v2. Lua fixtures execute via the installed interpreter.

**Iron extension:** a copied C29 `release-s79691` save identifies the blocker
at(-40,-14) as a same-force big electric pole. Its footprint intersects the
6→12-furnace extension. The shared operation now prepares replacement-first
pole clearance before mine growth, verifies every old wire neighbor, preserves
dependent power coverage, recovers the old pole through bots, and rechecks the
footprint. It contains no coordinate-specific repair or Laya geometry branch.
Foreign/unknown infrastructure still refuses safely.

Review fixes preserve explicitly owned sibling in-flight poles, exclude ghost
poles from live power coverage, resurvey after each relocation, recover a newly
built replacement on failed wire verification, type incomplete retirement, and
prevent the initial-refinery dry-run from performing foundation placement.
