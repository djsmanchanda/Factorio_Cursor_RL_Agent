# Session handoffs

One dated file per session (`<Area>_Session_Handoff_<YYYY-MM-DD>.md`). Everything here except this README is gitignored: handoffs are local working notes for the next agent, not repository history.

Record durable facts in tracked documents: `CURRENT_STATUS.md`, area docs, and the evidence index `docs/rl/Laya_Current_Handoff.md`. Handoffs are evidence, not current instructions.
